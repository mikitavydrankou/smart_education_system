# Multimodal adaptation

Extend the source-grounded workspace with generated relationship diagrams, narrated audio and genuinely manipulable activities. Polish UI, current design, exact source references and manual user control remain required.

New courses contain a small typed node/edge diagram per concept, a narration script, and one content-specific activity: ordering, matching or classification. Validate all references, exact item membership, distinct labels, solution bounds and source evidence. Render diagrams as original accessible SVG plus a text relationship list; do not execute generated HTML/code. Render activities through shared deterministic components with touch, keyboard/select/button alternatives to pointer dragging. Save current activity choices and first-check outcomes; repeated checks must not inflate adaptive evidence.

Audio: server-side OpenRouter speech synthesis returns real audio without requiring a system voice. Provide standard play/pause/seek/rate, transcript, explicit loading/error/cancel and local browser speech fallback. No audio autoplay. Bound input, response bytes, concurrency/timeouts and per-process request frequency; keys stay server-side. Cache audio only in the current browser session and revoke blob URLs on cleanup.

Policy: initial presentation follows stated preference. Attribute each first quiz/retry outcome to the latest explicitly viewed teaching format, never temporary quiz entry. An error offers a different available representation with an explanation; success history can influence the next topic after at least two observations. Manual format changes override automatic selection; a visible automatic-selection toggle allows opting out. Interactive outcomes are tracked separately from quiz totals, and only a first check per concept contributes. Recommendations are transparent heuristics with sample counts, not permanent learning-type diagnoses. Preserve preference, automatic mode, outcome evidence, activity drafts and recommendations on refresh.

Compatibility: migrate existing version-1 courses/progress without deleting them. Legacy lessons receive honestly labelled source-derived diagrams/activities; strict new-generation validation still requires all rich fields. Keep the original snapshot replay validation as the migration gate. A separate optional rich-media enhancement can be deferred; existing courses must work immediately without a paid call.

Tests: invalid diagrams/activities; all three deterministic graders; deduplicated outcomes, attribution, opt-out and manual overrides; v1 restoration; pointer/keyboard activity workflows and refresh; audio success/failure/cleanup; source-grounded real model generation and real TTS request; current demo/import/retry/results suite. Retain the documented WebKit host limitation.
